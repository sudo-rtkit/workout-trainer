# M3 Core Loop Implementation Plan (Setup → Generate → Log → Swap)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the mobile app's core loop — equipment setup, on-device session
generation, and session logging with PR detection, previous-performance display, a rest
timer, and mid-workout exercise swap — running against a real (non-service-role) dev user,
with every non-trivial piece of logic isolated into directly-testable hooks/functions.

**Architecture:** Screens are thin render layers (`apps/mobile/src/screens/`) that only
read from hooks and call hook methods — they get jest-expo mount-and-elements smoke tests
only, never RTL behavioral suites. All logic lives in hooks (`apps/mobile/src/hooks/`) and
plain functions (`apps/mobile/src/lib/`, `apps/mobile/src/data/`), each independently unit-
or behavior-tested with the Supabase client mocked only at a thin repository boundary. One
`useActiveSession` instance is shared across the Generate→Logging screen flow via React
Context (`ActiveSessionProvider`), since plain hook calls in two different screen components
would otherwise create two independent, non-communicating instances. A new `swapExercise()`
pure function joins `generate()` in `packages/rule-engine`, keeping all selection/generation
logic in the zero-dependency package.

**Tech Stack:** TypeScript 5, Expo/React Native, React Navigation (native-stack),
`@supabase/supabase-js`, jest-expo + `@testing-library/react-native` (already present from
M0), Vitest (rule-engine package, already present from M0–M2).

## Global Constraints

- Screens are thin render layers; screens get jest-expo mount-and-elements smoke tests
  only — no RTL behavioral suites (no `fireEvent`-driven assertions about business outcomes)
  on screen files. Behavioral coverage lives entirely in hook test files.
- Any logic (state transitions, computed display values, timers, data mapping, form
  selection state that drives a real decision) lives in a plain hook or function with full
  TDD/behavioral coverage — never inline in a screen component.
- Mock at the repository boundary (`apps/mobile/src/data/repository.ts`) in hook tests —
  never deep-mock the Supabase query-builder chain (`.from().select().eq()...`).
- `packages/rule-engine` stays zero-HTTP/zero-DB. `swapExercise()` is a pure function; it
  does not import anything from `apps/mobile` or touch persistence.
- The repository has zero generation knowledge: `createSession()` accepts a
  `GenerationResult`-shaped input and persists it. Only `useActiveSession` calls both
  `generate()`/`swapExercise()` and the repository.
- `useActiveSession` owns the rest-timer-start decision (composes `useRestTimer`
  internally and calls its `start()` after a successful `logSet()`) — screens never call
  `useRestTimer` directly or decide when a timer starts.
- One `useActiveSession` instance is shared across `GenerateScreen` and `LoggingScreen` via
  `ActiveSessionProvider` (React Context) — calling the hook separately in each screen
  would silently create two disconnected instances, since plain hooks don't share state
  across sibling/descendant component trees without a context or store.
- Every fetch-shaped hook returns `{ data, isLoading, error, refetch }`.
- `useEffect`-based fetches use an ignore-flag cleanup to guard against state updates after
  unmount.
- `exercises.movement_pattern` is nullable in the DB; `Exercise.movementPattern` (rule-engine
  type) is non-null. The mapping contract: `movementPattern: row.movement_pattern ?? 'untagged:' + row.id`,
  `isCompound: row.is_compound ?? false`, plus an explicit `isTagged: row.movement_pattern !== null`
  boolean so nothing string-matches the sentinel prefix.
- Every user-owned table's row **must** be inserted with an explicit `user_id` — none of
  `equipment_profiles`/`sessions` default `user_id` to `auth.uid()` at the column level
  (only the RLS policy checks it after the fact); the repository must fetch the current
  user's id via `supabase.auth.getUser()` and set it explicitly on every insert to a
  user-owned table.
- `session_exercises.id` and `sets.id` are client-generated UUIDs (per M1's schema) — the
  repository must generate them client-side (`crypto.randomUUID()`, available in the
  Hermes/Expo runtime) before insert, never rely on a DB default.
- Local Supabase's default ports are `54321`/`54322`/etc. Do not hardcode any port-shifted
  values from any particular sandbox's local `supabase/config.toml` workaround into
  committed mobile app code or `.env.example` — always use the documented Supabase
  defaults there, with actual local values living only in a gitignored `.env`.

```ts
import { createClient } from '@supabase/supabase-js';

const SUPABASE_URL = process.env.SUPABASE_URL ?? 'http://127.0.0.1:54321';
const SUPABASE_ANON_KEY = process.env.SUPABASE_ANON_KEY;

if (!SUPABASE_ANON_KEY) {
  throw new Error(
    'SUPABASE_ANON_KEY env var is required (run `pnpm exec supabase status` to get it)',
  );
}

async function main() {
  const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

  const { data, error } = await supabase.auth.signInWithPassword({
    email: 'dev@example.com',
    password: 'devpassword123',
  });

  if (error) {
    console.error('Dev-user sign-in FAILED:', error.message);
    console.error(
      'Check supabase/seed.sql: instance_id, email_confirmed_at, aud/role on auth.users, ' +
        'and the matching auth.identities row are all required for signInWithPassword to work.',
    );
    process.exit(1);
  }

  if (!data.user || data.user.id !== 'dddddddd-dddd-dddd-dddd-dddddddddddd') {
    console.error('Sign-in succeeded but returned an unexpected user:', data.user);
    process.exit(1);
  }

  console.log('Dev-user sign-in verified OK — user id:', data.user.id);
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

```ts
function run(command: string) {
  console.log(`> ${command}`);
  execSync(command, { stdio: 'inherit' });
}

async function main() {
  run('pnpm exec supabase db reset');

  const supabaseUrl = process.env.SUPABASE_URL ?? 'http://127.0.0.1:54321';
  const serviceRoleKey = process.env.SUPABASE_SERVICE_ROLE_KEY;

    throw new Error(

    );

  process.env.SUPABASE_URL = supabaseUrl;
  process.env.SUPABASE_SERVICE_ROLE_KEY = serviceRoleKey;

  run('pnpm exec tsx scripts/seed-exercises.ts');

  if (existsSync('scripts/data/movement-tags-review.json')) {
    run('pnpm exec tsx scripts/apply-movement-tags.ts');
  } else {

        'Exercises will be untagged (movement_pattern NULL); the app functions correctly ' +
        'via the sentinel fallback in toEngineExercise, just with degraded dedup quality. ' +
        'Run scripts/tag-exercises.ts + a human review pass, then re-run db:reset, when ready.',
    );
  }

  console.log('db:reset complete.');
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

```ts
import type { Exercise } from './types.js';

export interface TaggedExercise extends Exercise {
  isTagged: boolean;
}

export interface SessionExerciseRef {
  exerciseId: string;
  movementPattern: string;
}

export interface ScoredCandidate {
  exercise: TaggedExercise;
  rung: 1 | 2;
}

export interface SwapResult {
  candidates: ScoredCandidate[];
  reason?: 'no-equipment-match' | 'no-alternatives';
}

export function swapExercise(
  library: TaggedExercise[],
  session: SessionExerciseRef[],
  targetIndex: number,
  equipmentProfile: string[],
): SwapResult {
  const target = session[targetIndex];
  const targetExercise = library.find((e) => e.id === target.exerciseId);
  if (!targetExercise) {
    return { candidates: [], reason: 'no-alternatives' };
  }

  const sessionExerciseIds = new Set(session.map((s) => s.exerciseId));
  const otherSessionPatterns = new Set(
    session.filter((_, i) => i !== targetIndex).map((s) => s.movementPattern),
  );

  const availableEquipment = new Set(equipmentProfile);
  const equipmentEligible = library.filter(
    (e) =>
      !sessionExerciseIds.has(e.id) &&
      e.requiredEquipmentIds.every((id) => availableEquipment.has(id)),
  );

  if (equipmentEligible.length === 0) {
    return { candidates: [], reason: 'no-equipment-match' };
  }

  if (targetExercise.isTagged) {
    const rung1 = equipmentEligible.filter(
      (e) =>
        e.movementPattern === targetExercise.movementPattern &&
        e.primaryMuscles.some((m) => targetExercise.primaryMuscles.includes(m)),
    );
    if (rung1.length > 0) {
      return { candidates: sortCompoundFirst(rung1).map((exercise) => ({ exercise, rung: 1 as const })) };
    }
  }

  const rung2 = equipmentEligible.filter(
    (e) =>
      e.primaryMuscles.some((m) => targetExercise.primaryMuscles.includes(m)) &&
      !otherSessionPatterns.has(e.movementPattern),
  );
  if (rung2.length > 0) {
    return { candidates: sortCompoundFirst(rung2).map((exercise) => ({ exercise, rung: 2 as const })) };
  }

  return { candidates: [], reason: 'no-alternatives' };
}

function sortCompoundFirst(exercises: TaggedExercise[]): TaggedExercise[] {
  return [...exercises].sort((a, b) => Number(b.isCompound) - Number(a.isCompound));
}
```

```ts
export async function getExerciseLibrary(): Promise<ExerciseRow[]> {

    .from('exercises')
    .select('id, name, primary_muscles, secondary_muscles, movement_pattern, is_compound');
  if (exercisesError) throw exercisesError;

  const { data: links, error: linksError } = await supabase
    .from('exercise_equipment')
    .select('exercise_id, equipment_catalog_id');
  if (linksError) throw linksError;

  const equipmentByExercise = new Map<string, string[]>();
  for (const link of links) {
    const existing = equipmentByExercise.get(link.exercise_id) ?? [];
    existing.push(link.equipment_catalog_id);
    equipmentByExercise.set(link.exercise_id, existing);
  }

  return exercises.map((row) => ({
    ...row,
    required_equipment_ids: equipmentByExercise.get(row.id) ?? [],
  }));

export async function createSession(
  equipmentProfileId: string,
  result: GenerationResult,
): Promise<string> {
  const userId = await getCurrentUserId();

  const { data: session, error: sessionError } = await supabase
    .from('sessions')
    .insert({ user_id: userId, equipment_profile_id: equipmentProfileId, status: 'active' })
    .select('id')
    .single();

  const rows = result.exercises.map((exercise) => ({
    id: crypto.randomUUID(),
    session_id: session.id,
    exercise_id: exercise.exerciseId,
    order: exercise.order,
    target_sets: exercise.targetSets,
    target_reps: exercise.targetReps,
    rest_seconds: exercise.restSeconds,
  }));

  if (exercisesError) throw exercisesError;

  return session.id;

      weight,
      reps,

    .order('completed_at', { ascending: false })
    .limit(20);
  if (error) throw error;
  return data.map(({ weight, reps, completed_at }) => ({ weight, reps, completed_at }));
}
```

```ts
import { useCallback, useEffect, useState } from 'react';
import type { TaggedExercise } from '@app/rule-engine';
import { getExerciseLibrary } from '../data/repository';
import { toEngineExercise } from '../lib/toEngineExercise';

export interface UseExerciseLibraryResult {
  data: TaggedExercise[] | null;
  isLoading: boolean;
  error: string | null;
  refetch: () => void;
}

export function useExerciseLibrary(): UseExerciseLibraryResult {
  const [data, setData] = useState<TaggedExercise[] | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  const [refetchCount, setRefetchCount] = useState(0);

  useEffect(() => {
    let ignore = false;

    setIsLoading(true);
    setError(null);

    getExerciseLibrary()
      .then((rows) => {
        if (ignore) return;
        setData(rows.map(toEngineExercise));
        setIsLoading(false);
      })
      .catch((err: Error) => {
        if (ignore) return;
        setError(err.message);
        setIsLoading(false);
      });

    return () => {
      ignore = true;
    };
  }, [refetchCount]);

  const refetch = useCallback(() => {
    setRefetchCount((count) => count + 1);
  }, []);

  return { data, isLoading, error, refetch };
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react';

export interface UseRestTimerResult {
  remainingSeconds: number | null;
  isRunning: boolean;
  isComplete: boolean;
  start: (durationSeconds: number) => void;
  stop: () => void;
}

export function useRestTimer(): UseRestTimerResult {
  const [remainingSeconds, setRemainingSeconds] = useState<number | null>(null);
  const [isRunning, setIsRunning] = useState(false);
  const [isComplete, setIsComplete] = useState(false);
  const intervalRef = useRef<ReturnType<typeof setInterval> | null>(null);

  const clear = useCallback(() => {
    if (intervalRef.current !== null) {
      clearInterval(intervalRef.current);
      intervalRef.current = null;
    }
  }, []);

  const start = useCallback(
    (durationSeconds: number) => {
      clear();
      setRemainingSeconds(durationSeconds);
      setIsComplete(false);
      setIsRunning(true);

      intervalRef.current = setInterval(() => {
        setRemainingSeconds((current) => {
          if (current === null) return null;
          const next = current - 1;
          if (next <= 0) {
            clear();
            setIsRunning(false);
            setIsComplete(true);
            return 0;
          }
          return next;
        });
      }, 1000);
    },
    [clear],
  );

  const stop = useCallback(() => {
    clear();
    setRemainingSeconds(null);
    setIsRunning(false);
    setIsComplete(false);
  }, [clear]);

  useEffect(() => clear, [clear]);

  return { remainingSeconds, isRunning, isComplete, start, stop };
}
```

```ts
import { useCallback, useState } from 'react';
import { generate, swapExercise, type Goal, type TaggedExercise, type SwapResult } from '@app/rule-engine';
import {
  createSession,
  getSessionExercises,
  logSet as logSetRepository,
  getPreviousPerformance,
  updateSessionExercise,
} from '../data/repository';
import type { PreviousPerformanceRow } from '../data/types';
import { useRestTimer } from './useRestTimer';

export interface StartSessionInput {
  library: TaggedExercise[];
  availableEquipmentIds: string[];
  targetMuscleGroups: string[];
  goal: Goal;
  targetExerciseCount: number;
  equipmentProfileId: string;
}

interface SessionExerciseState {
  sessionExerciseId: string;
  exerciseId: string;
  movementPattern: string;
  targetSets: number;
  targetReps: number;
  restSeconds: number;
  setsLogged: number;
}

interface SessionState {
  id: string;
  exercises: SessionExerciseState[];
  shortfall: number;
  availableEquipmentIds: string[];
}

export interface UseActiveSessionResult {
  session: SessionState | null;
  currentExerciseIndex: number;
  isLoading: boolean;
  error: string | null;
  lastLoggedSetWasPr: boolean;
  previousPerformance: PreviousPerformanceRow[];
  restSecondsRemaining: number | null;
  isRestTimerRunning: boolean;
  isRestTimerComplete: boolean;
  startSession: (input: StartSessionInput) => Promise<boolean>;
  logSet: (weight: number, reps: number) => Promise<boolean>;
  swap: (targetIndex: number) => Promise<SwapResult>;
  confirmSwap: (targetIndex: number, newExerciseId: string) => Promise<void>;
}

export function useActiveSession(): UseActiveSessionResult {
  const [session, setSession] = useState<SessionState | null>(null);
  const [libraryRef, setLibraryRef] = useState<TaggedExercise[]>([]);
  const [currentExerciseIndex, setCurrentExerciseIndex] = useState(0);
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [lastLoggedSetWasPr, setLastLoggedSetWasPr] = useState(false);
  const [previousPerformance, setPreviousPerformance] = useState<PreviousPerformanceRow[]>([]);
  const restTimer = useRestTimer();

  const startSession = useCallback(async (input: StartSessionInput): Promise<boolean> => {
    setIsLoading(true);
    setError(null);
    try {
      const result = generate({
        exerciseLibrary: input.library,
        availableEquipmentIds: input.availableEquipmentIds,
        targetMuscleGroups: input.targetMuscleGroups,
        goal: input.goal,
        targetExerciseCount: input.targetExerciseCount,
      });

      const sessionId = await createSession(input.equipmentProfileId, result);
      const rows = await getSessionExercises(sessionId);

      const exercises: SessionExerciseState[] = rows.map((row) => {
        const exercise = input.library.find((e) => e.id === row.exercise_id);
        return {
          sessionExerciseId: row.id,
          exerciseId: row.exercise_id,
          movementPattern: exercise?.movementPattern ?? `untagged:${row.exercise_id}`,
          targetSets: row.target_sets,
          targetReps: row.target_reps,
          restSeconds: row.rest_seconds,
          setsLogged: 0,
        };
      });

      setLibraryRef(input.library);
      setSession({
        id: sessionId,
        exercises,
        shortfall: result.shortfall,
        availableEquipmentIds: input.availableEquipmentIds,
      });
      setCurrentExerciseIndex(0);

      const firstExerciseId = exercises[0]?.exerciseId;
      if (firstExerciseId) {
        setPreviousPerformance(await getPreviousPerformance(firstExerciseId));
      }
      return true;
    } catch (err) {
      setError((err as Error).message);
      return false;
    } finally {
      setIsLoading(false);
    }
  }, []);

  const logSet = useCallback(
    async (weight: number, reps: number): Promise<boolean> => {
      if (!session) throw new Error('logSet called with no active session');
      const current = session.exercises[currentExerciseIndex];
      setError(null);
      try {
        const result = await logSetRepository(current.sessionExerciseId, current.setsLogged + 1, weight, reps);
        setLastLoggedSetWasPr(result.is_pr);
        setSession({
          ...session,
          exercises: session.exercises.map((exercise, i) =>
            i === currentExerciseIndex ? { ...exercise, setsLogged: exercise.setsLogged + 1 } : exercise,
          ),
        });
        restTimer.start(current.restSeconds);
        return true;
      } catch (err) {
        // Not silently lost, not auto-retried — the failed set simply isn't recorded
        // locally or remotely; the caller (LoggingScreen) keeps the entered weight/reps
        // in the input fields so the user can just press Log Set again.
        setError((err as Error).message);
        return false;
      }
    },
    [session, currentExerciseIndex, restTimer],
  );

  const swap = useCallback(
    async (targetIndex: number): Promise<SwapResult> => {
      if (!session) throw new Error('swap called with no active session');
      const sessionRefs = session.exercises.map((e) => ({
        exerciseId: e.exerciseId,
        movementPattern: e.movementPattern,
      }));
      return swapExercise(libraryRef, sessionRefs, targetIndex, session.availableEquipmentIds);
    },
    [session, libraryRef],
  );

  const confirmSwap = useCallback(
    async (targetIndex: number, newExerciseId: string) => {
      if (!session) throw new Error('confirmSwap called with no active session');
      const target = session.exercises[targetIndex];
      await updateSessionExercise(target.sessionExerciseId, newExerciseId);

      const newExercise = libraryRef.find((e) => e.id === newExerciseId);
      setSession({
        ...session,
        exercises: session.exercises.map((exercise, i) =>
          i === targetIndex
            ? {
                ...exercise,
                exerciseId: newExerciseId,
                movementPattern: newExercise?.movementPattern ?? `untagged:${newExerciseId}`,
              }
            : exercise,
        ),
      });
    },
    [session, libraryRef],
  );

  return {
    session,
    currentExerciseIndex,
    isLoading,
    error,
    lastLoggedSetWasPr,
    previousPerformance,
    restSecondsRemaining: restTimer.remainingSeconds,
    isRestTimerRunning: restTimer.isRunning,
    isRestTimerComplete: restTimer.isComplete,
    startSession,
    logSet,
    swap,
    confirmSwap,
  };
}
```

```tsx
import { createContext, useContext, type ReactNode } from 'react';
import { useActiveSession, type UseActiveSessionResult } from './useActiveSession';

const ActiveSessionContext = createContext<UseActiveSessionResult | null>(null);

export function ActiveSessionProvider({ children }: { children: ReactNode }) {
  const activeSession = useActiveSession();
  return <ActiveSessionContext.Provider value={activeSession}>{children}</ActiveSessionContext.Provider>;
}

export function useActiveSessionContext(): UseActiveSessionResult {
  const context = useContext(ActiveSessionContext);
  if (!context) {
    throw new Error('useActiveSessionContext must be used within an ActiveSessionProvider');
  }
  return context;
}
```

```ts
import { useCallback, useEffect, useState } from 'react';
import { getEquipmentCatalog, createEquipmentProfile } from '../data/repository';
import type { EquipmentCatalogRow } from '../data/types';

export interface SaveResult {
  profileId: string;
  equipmentCatalogIds: string[];
}

export interface UseEquipmentSetupResult {
  catalog: EquipmentCatalogRow[];
  isLoading: boolean;
  error: string | null;
  refetch: () => void;
  selectedIds: Set<string>;
  toggle: (id: string) => void;
  isSaving: boolean;
  save: (name: string) => Promise<SaveResult>;
}

export function useEquipmentSetup(): UseEquipmentSetupResult {
  const [catalog, setCatalog] = useState<EquipmentCatalogRow[]>([]);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  const [selectedIds, setSelectedIds] = useState<Set<string>>(new Set());
  const [isSaving, setIsSaving] = useState(false);
  const [refetchCount, setRefetchCount] = useState(0);

  useEffect(() => {
    let ignore = false;
    setIsLoading(true);
    setError(null);
    getEquipmentCatalog()
      .then((rows) => {
        if (ignore) return;
        setCatalog(rows);
        setIsLoading(false);
      })
      .catch((err: Error) => {
        if (ignore) return;
        setError(err.message);
        setIsLoading(false);
      });
    return () => {
      ignore = true;
    };
  }, [refetchCount]);

  const refetch = useCallback(() => {
    setRefetchCount((count) => count + 1);
  }, []);

  const toggle = useCallback((id: string) => {
    setSelectedIds((current) => {
      const next = new Set(current);
      if (next.has(id)) next.delete(id);
      else next.add(id);
      return next;
    });
  }, []);

  const save = useCallback(
    async (name: string): Promise<SaveResult> => {
      setIsSaving(true);
      const equipmentCatalogIds = Array.from(selectedIds);
      const profileId = await createEquipmentProfile({ name, equipmentCatalogIds });
      setIsSaving(false);
      return { profileId, equipmentCatalogIds };
    },
    [selectedIds],
  );

  return { catalog, isLoading, error, refetch, selectedIds, toggle, isSaving, save };
}
```

```ts
import { useCallback, useState } from 'react';
import type { Goal, TaggedExercise } from '@app/rule-engine';
import { useActiveSessionContext } from './ActiveSessionContext';

const TARGET_EXERCISE_COUNT = 5;

export interface UseGenerateFormResult {
  selectedMuscles: Set<string>;
  toggleMuscle: (muscle: string) => void;
  goal: Goal | null;
  setGoal: (goal: Goal) => void;
  canGenerate: boolean;
  error: string | null;
  generate: (
    library: TaggedExercise[],
    equipmentProfileId: string,
    equipmentCatalogIds: string[],
  ) => Promise<boolean>;
}

export function useGenerateForm(): UseGenerateFormResult {
  const [selectedMuscles, setSelectedMuscles] = useState<Set<string>>(new Set());
  const [goal, setGoal] = useState<Goal | null>(null);
  const { startSession, error } = useActiveSessionContext();

  const toggleMuscle = useCallback((muscle: string) => {
    setSelectedMuscles((current) => {
      const next = new Set(current);
      if (next.has(muscle)) next.delete(muscle);
      else next.add(muscle);
      return next;
    });
  }, []);

  const generate = useCallback(
    async (
      library: TaggedExercise[],
      equipmentProfileId: string,
      equipmentCatalogIds: string[],
    ): Promise<boolean> => {
      if (!goal) throw new Error('generate() called with no goal selected');
      // Forward startSession's own return value directly — do NOT derive success from
      // reading `error` here instead; that would read the pre-await closure's stale value,
      // not the state update the await itself just triggered.
      return startSession({
        library,
        availableEquipmentIds: equipmentCatalogIds,
        targetMuscleGroups: Array.from(selectedMuscles),
        goal,
        targetExerciseCount: TARGET_EXERCISE_COUNT,
        equipmentProfileId,
      });
    },
    [goal, selectedMuscles, startSession],
  );

  return {
    selectedMuscles,
    toggleMuscle,
    goal,
    setGoal,
    canGenerate: selectedMuscles.size > 0 && goal !== null,
    error,
    generate,
  };
}
```

```tsx
import { useState } from 'react';
import { Button, Text, TextInput, View } from 'react-native';
import { useActiveSessionContext } from '../hooks/ActiveSessionContext';

export function LoggingScreen() {
  const {
    session,
    currentExerciseIndex,
    lastLoggedSetWasPr,
    previousPerformance,
    restSecondsRemaining,
    error,
    logSet,
  } = useActiveSessionContext();
  const [weight, setWeight] = useState('');
  const [reps, setReps] = useState('');

  if (!session) {
    return (
      <View>
        <Text>No active session.</Text>
      </View>
    );
  }

  const exercise = session.exercises[currentExerciseIndex];

  const onLogSet = async () => {
    const success = await logSet(Number(weight), Number(reps));
    if (success) {
      setWeight('');
      setReps('');
    }
    // On failure, keep the entered values so the user can just press Log Set again;
    // `error` (rendered below) explains what happened.
  };

  return (
    <View>
      <Text>{exercise.exerciseId}</Text>
      <Text>
        Set {exercise.setsLogged + 1} of {exercise.targetSets} — target {exercise.targetReps} reps
      </Text>
      {error && <Text>Couldn't log that set: {error}</Text>}
      {lastLoggedSetWasPr && <Text>🎉 New PR!</Text>}
      {previousPerformance.length > 0 && (
        <Text>
          Last time: {previousPerformance[0].weight}kg × {previousPerformance[0].reps}
        </Text>
      )}
      {restSecondsRemaining !== null && <Text>Rest: {restSecondsRemaining}s</Text>}
      <TextInput placeholder="Weight" keyboardType="numeric" value={weight} onChangeText={setWeight} />
      <TextInput placeholder="Reps" keyboardType="numeric" value={reps} onChangeText={setReps} />
      <Button title="Log Set" onPress={onLogSet} />
    </View>
  );
}
```

Note this screen no longer calls `useRestTimer` directly — the rest-timer-start decision
and its live state both come from `useActiveSessionContext()`, per the Global Constraints.
